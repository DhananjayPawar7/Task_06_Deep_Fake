# Process Log

## Objective

The purpose of this experiment was to determine how changes in
ElevenLabs Stability and Similarity settings affected the delivery of
the same analytical script.

## Tool

Platform: ElevenLabs
Feature: Text to Speech
Model: Eleven v4
Voice: Roger - Laid-Back, Casual, Resonant

I used a generic ElevenLabs voice rather than cloning the voice of an
identifiable person.

## Reason for the Second Attempt

For Attempt 2, I intentionally increased Stability and decreased
Similarity while keeping the voice, model, and script unchanged.

This created a controlled comparison in which the main variables were
the Stability and Similarity settings.

## Safety Filters / Refusals

I did not encounter a safety refusal during either generation attempt.
The experiment used a generic synthetic voice and an academic
sports-analysis narrative. No real person's voice was cloned.
